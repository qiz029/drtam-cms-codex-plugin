## Long description

Connect Codex to Dr Tam CMS through the official public CLI. Authorized team
members can work with Journal and website drafts, Media, treatment categories,
and translations. Publishing, deletion, clinical review decisions, channel
administration, and social delivery remain with authorized human administrators.

## Starter prompts

1. Connect this computer to Dr Tam CMS.
2. Show me the latest Journal drafts.
3. Help me update a CMS draft.

## Initial release notes

Initial skills-only submission. The Plugin installs the official Dr Tam CMS
workflow for Codex and uses administrator-approved, revocable Device Access
through `drtam-cms-cli`. It does not include an MCP server or browser hooks.
